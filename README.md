# PhysicsModule

A simple module containing functions and classes to build simple simulations or even calculations.

## Features

* Uses generators so saves space while working with massive simulations
* Efficient algorithm to calculate the evolution of complex systems with time
* Class system for easy modularity
* Easy built-in animation using matplotlib.animation.FuncAnimation
